# 🌍 Nodi Payanam — Travel Website

A modern, responsive travel website homepage built from scratch using **HTML5 and CSS3**.

Nodi Payanam is an original travel website concept designed to help users discover destinations, hotels, restaurants, and travel experiences through a clean and responsive interface.

> **Note:** This project is an original design and is not a clone of TripAdvisor, Booking.com, Airbnb, or any other existing travel platform.

---

## 📌 Project Overview

Nodi Payanam is a frontend travel website project created to practice and demonstrate core **HTML and CSS web development skills**.

The website includes:

* Travel destination discovery
* Hotel listings
* Restaurant listings
* Search interface
* Price and rating filters
* Responsive card layouts
* Navigation menu
* Mobile-friendly design
* Hover effects
* Responsive layouts for desktop, tablet, and mobile

---

## 🎯 Objective

The objective of this project is to build a **modern, attractive, and responsive travel website homepage using plain HTML and CSS**.

The project focuses on understanding:

* Semantic HTML
* CSS layouts
* Flexbox
* CSS Grid
* Responsive design
* Media queries
* Cards and reusable UI patterns
* Navigation design
* Hover effects
* Website spacing and alignment

## 🔮 Future Improvements

The current version is a **static HTML/CSS frontend**.

Future versions can add JavaScript and MERN stack functionality.

### Phase 1 — JavaScript

* Functional search

* Dynamic card filtering
* Image sliders
* Interactive menus
* Form validation

### Phase 2 — React

* State management

```text

  ↓
```
